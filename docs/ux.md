# 画面の決まり

トレイ・kanban・カレンダーと、これから作る Mac・iPhone・Watch のアプリが従う、見せ方と動きの決まり。形式の決まり（`format.md`）がデータの決まりで、この一枚が画面の決まり。

**画面は静かにしていて、自分の操作にだけ、その場で一度応える。**

## 1. 同じ状態は、どの画面でも同じ見え方をする

トレイ・kanban・カレンダーは、同じものを別の並べ方で見ている。状態の見せ方は次の表だけで、画面ごとに作らない。

| 状態 | 見え方 |
| --- | --- |
| 進行中 | 緑の縁と、経過時間（`● 0:42`） |
| 済み | 薄くして、取り消し線 |
| 次 | 「次」の印 |
| 今日に入っている | 「今日」の印 |
| 予定（Plan） | 薄い塗りと、破線の縁 |
| 遅れ（期限が明日まで・過ぎた、持ち越し、前の日から動いたまま） | 赤 |
| ここ（次、今週、落とし先） | アクセントの色 |
| つかんでいる | 薄くして、破線の縁 |
| どのプロジェクトか | 左の帯の色 |
| 手 | 青緑（`#14a3a3`） |

色の意味はこの表で全部。緑は「今日、自分の時間が動いた」ことだけに使う（進行中、済んだ瞬間、進みの帯）。状態（Backlog など）は色で塗らない。

## 2. 同じ操作は、どの画面でも同じ形でできる

始める・止める、今日に入れる、済みにする、消す。この四つは、行でもカードでも枠でも、同じアイコンと同じ言葉で出す。

| 操作 | アイコン | 言葉 |
| --- | --- | --- |
| 始める | `play` | 始める |
| 止める | `square` | 止める |
| 今日に入れる | `calendar-plus` | 今日に入れる |
| 今日から外す | `x` | 今日から外す |
| 済みにする | チェック、または Done へのドラッグ | 済みにする |
| 消す | メニューの中 | 消す |

押す部品は、押したあとも同じ場所にある。切り替えや絞り込みで並びが変わっても、切り替えるボタンと選ぶ欄は動かさない。使えない欄は、消さずに、押せない状態で残す。

## 3. 動きは三段だけ。よく起きることほど小さくする

| 段 | 長さ | 使う場面 | 頻度 |
| --- | --- | --- | --- |
| 小 | 0.2秒 | 現れる・始める・止める | 一日に何十回 |
| 中 | 0.7秒 | 一つ済んだ（チェック、Done に落とす） | 一日に数回 |
| 大 | 1.5秒 | 今日の分が全部済んだ | 一日に一回 |

- 動くのは、自分の操作で変わったものだけ。画面を開いた、日付を送った、描き直した、では動かさない。
- 動き続けるものは置かない。進み続けるのは、経過時間の数字だけ。
- 動きが無くても、同じことが分かるようにする。動きは返事で、情報ではない。OS の「視差効果を減らす」がオンなら、動かさない。
- 一つの操作で動かすのは一か所。カードが応えたら、件数や見出しは動かさない。進みの帯は、数字と同じく、変わったら新しい長さへ伸びる。
- 大だけは例外で、画面全体で応えてよい（帯・数字・行・紙片）。使うのは、今日の分が全部済んだ瞬間の一つだけ。
- 新しい動きは作らない。足したくなったら、三段のどれかに割り当てる。

長さと緩急は `overrides.css` の先頭の変数（`--ofc-fx-s`・`--ofc-fx-m`・`--ofc-fx-l`）だけが持つ。色も同じで、緑・赤・手の色は変数（`--ofc-running`・`--ofc-late`・`--ofc-hand`）を通す。`npm run lint` が、変数を通さない秒数と色、元に戻すを通さない削除を落とす（`scripts/check-ux.mjs`）。

## 4. 確認で止めず、取り返せるようにする

消す・外すは、確認の窓を出さずにすぐ行い、数秒だけ「元に戻す」を出す。

## 5. 知らせは、目の届かないことにだけ使う

- うまくいったことは、その場所の変化で伝える。右下の通知は出さない。
- 通知を出すのは、失敗したときと、見えない所で起きたこと（消したものを戻せる、など）だけ。
- 言葉は日本語。状態の名前（Backlog・Ready・In Progress・Review・Done）と見出しの名前（TODO・Memo・Plan・Log）は、ファイルに書いてある値なので、そのまま出す。

## 6. 保存しない、設定しない

進み・経過時間・動きは、その場で数えて出す。点数や連続日数のように、保存しないと出せないものは置かない。
